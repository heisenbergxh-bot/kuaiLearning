## 一、这是什么

快学（KuaiLearning）是一个**在浏览器里跑的 AI 学习工作台**。它不像传统的网课平台那样给你一堆预制好的视频——而是根据你设定的目标，**现场生成**适合你当前水平的课程，学一节生成一节。

背后的教育学理念来自 **知识→技能→智慧** 三层模型和 **最近发展区** 理论：不灌你一大堆"以后可能用得上"的东西，每节课只挑战刚刚好的难度，做完巩固再往前走。

### 和传统自学方式的区别

| 你通常怎么做 | 快学怎么做 |
|---|---|
| 自己搜教程，不知道从哪篇开始 | 先帮你厘清使命，再生成有序大纲 |
| 看了一堆但不知道自己掌握没有 | 课内测验 + 独立题库，即时反馈正确率 |
| 笔记、术语、参考链接散落各处 | 自动归档术语表、速查表、学习记录、资源 |
| 学偏了也不知道 | 每节课都锚定你的使命，始终围绕"为什么学" |
| 遇到问题没人问 | 每节课内置 AI 老师，基于课程内容答疑 |

## 二、核心功能

### 🎯 对话式使命设定

新建学习空间时，不是丢给你一张空白表单让你填——而是以聊天引导的方式，逐步帮你厘清五个关键问题：

1. **学什么**（Topic）—— 自由输入，比如"理解 Transformer 注意力机制"或"用 Rust 写一个 HTTP 服务器"
2. **为什么学**（Why）—— 这个动机会被反复喂给 AI，确保每节课围绕你的目标来教
3. **成功的样子**（Success Looks Like）—— 多选或自定义，比如"能给别人讲清楚""能独立实现一个 demo"
4. **约束与偏好**（Constraints）—— 比如"多用类比""配合 Python 代码示例"
5. **暂不涉及**（Out of Scope）—— 明确边界，防止 AI 跑偏

引导过程是纯本地模拟，不需要联网或 API Key。

### 🗺️ AI 生成学习大纲

填完使命后，AI 会根据你的目标生成一份**分阶段的学习路线图**：

- 通常包含 **3~5 个阶段**，共 **8~14 节课**
- 每节课有自己的标题和一句话描述，按从基础到进阶的顺序排列
- 所有内容用你选择的语言（中文/英文）生成

大纲不是一成不变的——你可以随时点 **"重新规划剩余"**，输入调整建议（比如"多一些实战项目""跳过基础语法""加入并发主题"），已学完的课程会保留，只重新规划后面的部分。

### 📖 逐节生成深度课程

在大纲中点击任意一节"生成本课"，AI 就会为该主题生成一份完整的**自包含 HTML 课程**，包含：

- 分层讲解（直觉理解 → 精确定义 → 实例演示 → 常见误区）
- 代码示例、对比表格
- 提示框（callout）—— 重点、注意事项、拓展阅读
- **1~2 道内嵌测验题**，点击选项即时反馈对错与解析

每节课是独立 HTML 文档，同时 AI 会自动帮你**一次生成配套沉淀**：

| 沉淀内容 | 说明 |
|---|---|
| 🧠 测验题 | 课内题目自动入库，后续可在题库集中练习 |
| 📚 术语 | 关键术语及其规范定义，统一全课程用词 |
| 📄 速查表 | 本课内容的压缩版参考文档，可一键打印 |
| 📝 学习记录 | 关键收获总结，用于推算下一课的难度 |
| 🔗 资源 | 课程引用的高质量外部链接自动归档 |

### 🧠 独立题库系统

所有课程的测验题自动汇集到题库，支持：

- 按课程筛选题目
- **练习模式**：逐题作答，即时反馈，统计正确率
- 正确率持久保存（IndexedDB），刷新页面不丢失

### 💬 AI 老师答疑

每节课页面下方有一个对话框，你可以就这节课的内容向 AI 提问。AI 会结合课程内容回答（自动带入最近 10 条对话上下文），像一个随时在线的辅导老师。

### 📊 进度追踪

- 每节课可"标记完成"，大纲中对应项变为 ✓
- 课程完成数、测验正确率一目了然
- 大纲整体完成进度实时可见

### 🌐 多工作区 + 中英双语

- **多个学习空间**：可以同时维护多个学习主题，互不干扰
- **界面语言**：支持中文 / English 切换
- **AI 生成内容语言**：跟随设置中的语言选项

## 三、快速上手

### 前置条件

- **Node.js ≥ 20.19**（Vite 8 要求，推荐 LTS 版本）
- 一个 **OpenAI 兼容的 API Key**（DeepSeek / OpenAI / 自定义均可）

### 启动

```bash
git clone <仓库地址>
cd kuaiLearning-app
npm install
npm run dev
```

浏览器打开 `http://localhost:5173`。

### 三步开始学习

**第一步：配置 AI**

左下角 ⚙️ 设置 → 选择服务商（默认 DeepSeek）→ 填入 API Key → 选择模型 → 保存。

> 第一次用 DeepSeek 的话，去 [platform.deepseek.com](https://platform.deepseek.com) 注册就能拿到 Key，价格很低。

**第二步：新建学习空间**

左侧栏点 **+ 新建** → 在聊天引导中逐步填写使命 → 确认汇总 → 完成。

**第三步：生成大纲 → 学第一课**

进入「📖 课程」→ 点 **生成学习大纲** → 在大纲中选第一节课点 **生成本课** → 生成完毕后点 **查看课程** → 阅读 + 做测验 + 标记完成。

## 四、深度使用技巧

### 使命写得越好，课程质量越高

使命不是一个"随便填填"的表单——它是 AI 生成课程时最重要的上下文。几个技巧：

- **"为什么学"** 写具体动机，比如"我想看懂 Transformer 论文的数学推导，不是泛泛了解"比"想学 AI"强得多
- **"成功的样子"** 选得越实在越好，"能独立实现一个微型 Transformer 并训练"比"掌握知识"更有指导性
- **"约束"** 里可以写学习偏好：多用视觉化类比、配合代码示例、控制单节课时长等
- **"暂不涉及"** 明确排除不关心的分支，防止大纲膨胀

### 大纲是活的

如果学了几节发现方向不对，别重建——点 **重新规划剩余**，输入调整建议。已生成的课程会保留，只改后面。

### 题库的正确打开方式

- 学完一个阶段后，去题库按阶段筛选题目集中练习
- 练习模式会追踪每道题的正确率，重复错的题多练几遍
- 题库里做错的题，可以回去翻对应课程的速查表温习

### 善用速查表

每节课配套生成的速查表是可打印的压缩版参考文档。学完一个主题后把所有速查表打印/导出，比翻课程快得多。

## 五、优点

### ✅ 个性化定制，不是千篇一律的课程

同样的"学 Rust"，不同的人得到的课程完全不同——取决于你的使命、已有基础、学习偏好。AI 根据你的学习记录动态调整后续难度。

### ✅ 一次生成，多方沉淀

生成一节课的同时，术语、测验题、速查表、学习记录、参考资源全部自动入库。你只管学，整理的事 AI 干了。

### ✅ 纯本地，隐私安全

所有数据——学习内容、进度、设置——全部存在你浏览器本地（IndexedDB + localStorage）。没有后端服务器，不上传任何学习数据。你的学习内容只有你自己能看到。

### ✅ 免费使用（除 AI 调用费）

工具本身完全免费开源。唯一的成本是你调用的 AI API 费用——以 DeepSeek 为例，生成一整套课程（大纲 + 8~14 节课）的费用大约几毛到一块钱人民币。

### ✅ 支持任意 OpenAI 兼容接口

不绑定特定厂商。DeepSeek、OpenAI、Ollama 本地模型、或其他兼容 `/chat/completions` 的服务都能用。你可以随时切换模型或服务商。

### ✅ 离线使命设定

填写使命的引导对话是纯本地模拟的，不需要联网，不消耗 API 额度。只有生成大纲/课程/答疑时才调用 AI。

## 六、局限与已知问题

### ❌ 纯浏览器存储，没有云端同步

**这是目前最大的局限。** 所有数据在浏览器本地：

- 换浏览器 → 数据没了
- 清除站点数据 → 数据没了
- 无痕/隐私模式 → 关闭后数据没了
- 换电脑 → 数据不跟随

**当前建议**：固定用同一个浏览器、同一份配置；重要内容自行截图或复制备份。

### ❌ API Key 明文存储

API Key 存在浏览器 `localStorage` 中，明文可读。任何能访问你浏览器的人（或浏览器扩展）都可能读到。**请仅在自己的个人设备上使用。**

### ❌ 依赖外部 AI 服务

- 需要稳定的网络连接
- AI 服务异常或额度耗尽时，无法生成新课程
- AI 生成内容的质量受模型能力影响——用 GPT-4 和用 DeepSeek-Chat 的课程质量确实有差异
- 需要 AI 服务允许浏览器跨域请求（CORS），部分自定义接口可能受限

### ❌ 没有内容导出/导入

目前无法将课程、术语、题库导出为文件，也无法从文件恢复。如果你积累了大量的学习内容，无法迁移到新设备或分享给别人。

### ❌ 单机运行，非 SaaS

需要自己安装 Node.js 并在本地启动。没有托管版本，无法直接用浏览器打开一个网址就开始用——对非技术用户有门槛。

### ❌ AI 生成内容偶有瑕疵

虽然是结构化 prompt + 容错解析，但 AI 偶尔会：
- 给出不够准确的表述（尤其在专业领域深度较深时）
- 测验题答案有争议
- JSON 格式不完美导致解析需要重试

### ❌ 学习体验依赖"你会提问"

AI 老师的答疑质量取决于你提问的方式。如果你不太清楚自己哪里不懂，很难得到精准解答。

## 七、未来演进方向

以下按优先级排列，**粗体**为近期计划：

### 🔴 P0 — 数据持久化与迁移

1. **导出/导入功能**：支持将工作区（含所有课程、术语、题库、记录）导出为单个 JSON/ZIP 文件，并可导入恢复。
2. **云端同步（可选）**：接入 WebDAV、GitHub Gist 或自建后端，实现跨设备同步。保持"默认本地、可选云同步"的设计哲学。
3. **自动备份提醒**：定期提醒用户备份数据。

### 🟡 P1 — 学习体验增强

4. **间隔复习系统**：基于艾宾浩斯遗忘曲线，在题库中自动安排已做题目的复习时间，强化长期记忆。
5. **学习笔记**：在课程阅读过程中支持划线、批注，笔记自动关联到对应课程。
6. **学习统计面板**：可视化展示学习时长、课程完成趋势、测验正确率曲线、术语掌握度等。
7. **课程评价与反馈**：学完一节后给课程打分/写反馈，帮助后续课程生成得更贴合自己。

### 🟢 P2 — 内容与协作

8. **课程分享**：将自己生成的课程（或整个大纲）导出为可分享的链接/文件，别人可以导入到自己的快学中。
9. **多模型对比**：同一主题用不同模型各生成一份，方便对比质量选最优。
10. **Prompt 模板市场**：社区共享使命模板（如"30 天学会 Python 数据分析""前端面试系统准备"），一键导入使用。
11. **语音输入 / TTS 朗读**：支持语音输入提问，AI 朗读课程内容。

### 🔵 P3 — 平台化

12. **PWA 支持**：打包为 PWA，可"安装"到桌面，支持部分离线功能。
13. **Docker 一键部署**：提供 Docker 镜像，降低非技术用户的启动门槛。
14. **移动端适配**：优化手机/平板阅读体验。
15. **多语言扩展**：界面和 AI 生成内容支持更多语言（日语、韩语等）。

## 八、常见问题

**Q：使命设定需要 API Key 吗？**
不需要。使命设定是纯本地的引导式对话，不调用 AI。

**Q：生成一节课大概多久？**
取决于模型和课程复杂度，通常 10~60 秒。流式生成可以实时看到内容产出。

**Q：生成课程失败怎么办？**
先确认 API Key 有效、模型可用、接口允许跨域（CORS）。大多数情况重试一次即可。目前课程解析有容错机制，偶尔格式不完美也能提取出正确内容。

**Q：课程内容深度够吗？**
每节课追求"讲透一个小主题"而非面面俱到。深度取决于你设定的使命和选择的模型。如果觉得不够深，可以在使命约束中写明"追求严谨的数学推导"或"要求教科书级别的准确性"。

**Q：可以不用 DeepSeek，用自己的模型吗？**
可以。设置页选"自定义"，填入任意 OpenAI 兼容的 Base URL 和模型名（包括本地 Ollama、vLLM 等）。

**Q：能不能部署到服务器上用？**
`npm run build` 生成静态文件到 `dist/`，部署到任意静态托管（Nginx、Vercel、GitHub Pages）即可。注意：仍然是纯前端，数据依然存在每个用户的浏览器本地。

**Q：和 Notion AI / ChatGPT 学习有什么不同？**
快学的核心差异在于**结构和沉淀**——不是"聊天式学习"，而是强制你先想清楚使命 → 生成有序大纲 → 逐节学 → 自动沉淀。你用 ChatGPT 也能学东西，但术语、测验、速查表、学习记录这些东西 Chat 完就丢了，快学帮你留下来了。
